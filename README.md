# AI Time Machine 🚀⏰

An interactive web application that lets you travel through time and experience immersive historical eras. Built with Next.js, TypeScript, and Tailwind CSS for the GitHub Copilot Day Contest.

## Features

✨ **Premium Interactive Experience**
- Enter any historical year and instantly travel through time
- Cinematic loading animations with time-portal transitions
- Fully responsive design for mobile and desktop
- Smooth Framer Motion animations throughout

🏛️ **Historical Content**
- 10 complete historical periods from 3000 BC to 2026 AD
- Detailed information on:
  - Historical eras and locations
  - Important historical figures
  - Major events and achievements
  - Technology and innovations
  - Fascinating historical facts

🎨 **Modern Design**
- Glassmorphism UI elements
- Cinematic dark theme with gradient backgrounds
- Ancient Greek architectural inspirations
- Futuristic AI interface elements
- Professional typography and spacing

## Getting Started

### Prerequisites
- Node.js 18+ and npm/yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Open browser and navigate to
http://localhost:3000
```

### Build for Production

```bash
npm run build
npm start
```

- **Framework**: Next.js 14

## Usage

1. **Open the Application**: Navigate to the home page
2. **Enter a Year**: Type any historical year (3000 BC - 2026 AD)
3. **Travel Through Time**: Click "TRAVEL THROUGH TIME" button
4. **Experience History**: View detailed information about the era
5. **Return to Present**: Click "RETURN TO PRESENT" to go back
